== Organización sugerida

Cada equipo debe trabajar mediante tareas pequeñas y revisables. Las interfaces entre equipos deben definirse mediante el contrato OpenAPI para reducir dependencias directas.

El equipo Backend debe publicar temprano una primera versión del contrato API para permitir que los equipos frontend avancen en paralelo.
