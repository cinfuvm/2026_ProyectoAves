= Requisitos funcionales

== Cuentas y acceso

[cols="1,3"]
|===
|ID |Requisito

|RF-01
|Registro de usuarios.

|RF-02
|Inicio y cierre de sesión en móvil y dashboard.

|RF-03
|Roles: usuario, moderador y administrador. Solo los dos últimos acceden al dashboard.

|RF-04
|Edición de perfil básico.
|===

== Catálogo de aves

[cols="1,3"]
|===
|ID |Requisito

|RF-05
|CRUD completo de aves para administradores.

|RF-06
|Buscador por nombre y categoría mediante API REST.

|RF-07
|Ficha de ave con datos del proyecto base “Aves de Chile” y fotografías de avistamientos.
|===

== Bitácora de avistamientos

[cols="1,3"]
|===
|ID |Requisito

|RF-08
|Registrar avistamiento con lugar, fecha, comentario y fotografía.

|RF-09
|Editar y eliminar los propios avistamientos.

|RF-10
|Consultar la bitácora personal.

|RF-11
|Consultar fotografías de otros usuarios filtradas por ave o categoría.

|RF-12
|Agregar fotografías de otros usuarios a una colección personal.
|===

== Moderación y popularidad

[cols="1,3"]
|===
|ID |Requisito

|RF-13
|Reportar una fotografía que no corresponda a un ave.

|RF-14
|Cola de reportes para moderadores con acciones de aprobar o retirar.

|RF-15
|Sección “Aves populares” basada en las visualizaciones de usuarios.
|===

== Dashboard y landing

[cols="1,3"]
|===
|ID |Requisito

|RF-16

|RF-17
|Gestión de aves y colecciones personales de avistamiento.

|RF-18
|Landing page que invite a instalar la aplicación móvil.
|===
